# Brainstorm: a study-notes swap club

Nothing here is a plan. If it becomes real, it gets a page in `projects/` that links back here.

## The idea (Alex, 2099-09-28)

"What if there was a club where people swap their own lecture summaries before midterms, like a library of everyone's notes, sorted by course?"

## Quick check

- **Does it exist already?** The campus learning center runs course study groups but no notes library. [Source: learning center page, read 2099-09-28]
- **What would it take?** A shared folder, a sign-up form, and a faculty advisor for club registration.
- **Why it might not work:** some courses forbid sharing materials. DEMO 101's policy allows discussion but not shared write-ups ([[school/courses/demo-101]]), so each course's policy would need checking. Notes quality varies.

## Open questions

- Would the club only accept summaries in the student's own words, never the course's slides or solutions?
- Could it reuse the StudyBuddy-Example code ([[projects/2099-example-state-hack]])?
