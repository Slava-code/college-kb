# brainstorms/

Loose idea pages: project ideas, essay angles, club event ideas, "what if" explorations. Nothing here is a plan or a fact until it moves to its own page elsewhere. One page per brainstorm (`type: brainstorm` or `note`), named `YYYY-MM-DD-<slug>.md`.

Template: `schema/templates/brainstorm.md`. DEMO: `2099-09-28-notes-swap-club.md`.

Allowed types: `brainstorm`, `note`. Commit scope: `brainstorms`.
