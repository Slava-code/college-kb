# projects/

Personal and team projects that outlive one session: side projects, hackathons, club builds, research code. One page per project (`type: project`), with goal, status, links to repos, teammates (wikilinks to `people/`), and a Timeline. Course assignments stay with their course under `school/`.

Templates: `schema/templates/project.md`, `hackathon.md` (events: dates, rules, what you built, what to reuse in applications), `plan.md` for a project that has not started. DEMO: `2099-example-state-hack.md`.

Allowed types: `project`, `plan`, `note`. Commit scope: `projects`.
