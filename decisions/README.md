# decisions/

Decisions worth remembering the reasoning for: choosing a major or minor, picking between offers, dropping a course, housing. One page per decision (`type: decision`), named `YYYY-MM-DD-<slug>.md`.

Each page records the question, the options considered, what was decided and why, sources (`[Source: ...]`), and what would make you revisit it. A superseding decision links back with a resolution stamp; the old page is never edited to hide history.

Template: `schema/templates/decision.md`. DEMO: `2099-09-04-drop-math-2xx-example.md` (the decision behind the dropped DEMO course).

Allowed types: `decision`. Commit scope: `decisions`.
