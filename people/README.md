# people/

One page per person you deal with repeatedly: instructors, TAs, advisors, mentors, recruiters, teammates (`type: person`). Record role, how you know them, how to reach them through official channels, and what they said that matters, each with `[Source: ...]`.

Check `GLOSSARY.md` before creating a page and add the person's aliases there. Keep it professional: no sensitive personal details about other people, and nothing you would not want them to read.

Template: `schema/templates/person.md`. DEMO: `prof-example.md` (a fictional instructor).

Allowed types: `person`. Commit scope: `people`.
