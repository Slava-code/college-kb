# lists/

Short-term lists that are useful now and stale later: errands, packing, groceries, read-later bundles, "before finals week". One page per list (`type: list`), often named with a week or date (`YYYY-wNN-<slug>.md`). Roll forward or archive when done.

Template: `schema/templates/list.md`. DEMO: `2099-w41-midterm-week.md`; an archived one is in `archive/lists/`.

Allowed types: `list`. Commit scope: `lists`.
