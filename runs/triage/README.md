# runs/triage/

One report per triage run, named `YYYY-MM-DD-HHMM-triage.md`: gates checked, drops read, pages written or updated, reminders recorded, drops removed, questions for the student (at most `NEEDS_OWNER_MAX_QUESTIONS`), and anything skipped with the reason. Reports summarize; they do not copy sensitive drop content.

Template: `schema/templates/triage-report.md` (`type: report`). DEMO: `2099-09-29-0800-triage.md`.
