# research/

Synthesis across sources: a literature sweep for a paper, a comparison of grad programs, a deep dive before a decision. One memo per question (`type: research`), named `YYYY-MM-DD-<slug>.md`; a multi-file run may use a folder `YYYY-MM-DD-<slug>/` with a `README.md` and per-part pages.

Every claim cites a source page or a URL. Keep hedges from the sources. State the question at the top and the answer (or "unresolved") right under it.

Templates: `schema/templates/research-memo.md` for each memo or part, `research-run-readme.md` for a run folder's README. A run's README is freeform and not indexed, so its `synthesis.md` carries the `description:` that appears in `INDEX.md`; link the run as `[[research/<run-folder>]]`. DEMO run: `2099-09-26-summer-research-programs/` (README, synthesis, two sweeps).

Allowed types: `research`. Commit scope: `research`.
