# archive/

Superseded or inactive pages, mirroring the original folder structure (e.g. `archive/school/courses/demo-101.md`). Pages move here by proposal, never by silent deletion, and keep their history. Finished semesters are good candidates after `ARCHIVE_STALE_MONTHS` (THRESHOLDS.md).

Archived pages keep their original `type:`; the `archive/` folder is not type-checked by `kb-lint.py`. Set `status: archived` and note the archive date at the top. DEMO: `lists/2099-w35-move-in-week.md`.

Commit scope: `archive`.
