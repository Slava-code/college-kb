# inbox/

Capture landing zone. Drops arrive here as verbatim, timestamped files from `scripts/kbdrop.sh` (`YYYY-MM-DD-HHMM-<slug>.md`) with only `via:` and `captured:` frontmatter.

Never answer from the inbox. On-demand triage (when you ask for it) absorbs drops into pages, lists and reminder ledgers, then removes each drop only after its content is committed elsewhere.

You rarely write a drop by hand; if you do, `schema/templates/inbox-drop.md` shows the shape. DEMO: `2099-10-01-1525-prof-example-office-hours-moving.md`, a drop still waiting for triage (the DEMO course page has not absorbed it, which is the point).

Commit scope: `inbox` for captures, `triage` for absorption runs.
